# 매칭문자 (안드로이드 앱)

RAW 명단(엑셀)과 휴대폰 연락처를 전화번호로 비교해 매칭된 사람에게 문자를 보내는 앱입니다.
명단과 연락처는 휴대폰 안에서만 처리되고, 외부로 전송되지 않습니다. 인터넷 권한도 없습니다.

## APK 만드는 방법 A — GitHub (PC에 프로그램 설치 불필요)

1. github.com에 가입하고 로그인합니다.
2. 오른쪽 위 **+** → **New repository** → 이름 `matching-sms` → **Private** 선택 → Create.
3. 새 저장소 화면의 **uploading an existing file** 링크를 누릅니다.
4. 압축을 푼 `ContactMatchSms` 폴더 **안의 내용 전체**(app, .github, build.gradle 등)를 끌어다 놓고 **Commit changes**를 누릅니다.
   - `.github` 폴더가 숨김이라 안 보이면 탐색기 보기 → 숨긴 항목 표시를 켜세요.
5. 상단 **Actions** 탭 → "APK 빌드"가 자동 실행됩니다(약 3~5분). 실행되지 않으면 **Run workflow**를 누르세요.
6. 초록색 ✓ 표시가 뜨면 해당 실행을 눌러 아래 **Artifacts**의 `매칭문자-apk`를 내려받습니다(zip 안에 .apk).

## APK 만드는 방법 B — Android Studio

1. Android Studio 설치 → **Open** → `ContactMatchSms` 폴더 선택.
2. Gradle 동기화가 끝나면 메뉴 **Build → Build App Bundle(s) / APK(s) → Build APK(s)**.
3. `app/build/outputs/apk/` 아래에 APK가 생깁니다.

## 휴대폰에 설치

1. APK 파일을 휴대폰으로 옮깁니다(카카오톡 나에게 보내기, USB 등).
2. 파일을 누르면 "출처를 알 수 없는 앱" 경고가 뜹니다 → **설정** → **이 출처 허용** → 설치.
3. Play 프로텍트 경고가 뜨면 **세부정보 → 무시하고 설치**를 누릅니다(직접 만든 앱이라 뜨는 정상 경고).

## 사용법

1. **RAW 명단 불러오기**: 엑셀/CSV 선택 (연락처·이름·추천인 열 자동 인식)
2. **내 연락처 불러오기**: [휴대폰 연락처에서 선택] → 권한 허용 → 전체 연락처 자동 불러오기
   (또는 .vcf / 엑셀 파일)
3. 매칭 결과 확인 → 문자 내용 입력 (`{이름}`은 내 연락처에 저장된 이름으로 바뀜)
4. 하단 **[✉️ 문자 보내기]** → 기본 문자앱이 내용이 채워진 채로 열림 → 전송 → 앱으로 돌아오면 다음 사람
5. 발송완료 표시는 앱에 저장되며, [매칭명단 엑셀 저장]은 휴대폰 **다운로드** 폴더에 저장됩니다.

## 참고

- 문자는 휴대폰 기본 문자앱으로 한 명씩 보냅니다(통신사 요금제 적용).
  하루에 대량으로 보내면 통신사 스팸 차단이 걸릴 수 있으니 나눠서 보내세요.
- 선거 관련 문자는 공직선거법의 문자 발송 규정(횟수·방식·시기 제한)을 확인하고 보내세요.
- 최소 지원: 안드로이드 8.0 이상
